# SplatForge 0.0.1a1 — prototype preview

Released: 2026-10-15.

This is an early public snapshot of an operator-first Gaussian Splatting
research project. The project remains in its feasibility stage; APIs may
change substantially.

## Included

- Versioned operator runtime and explicit provider/capability contracts.
- Gaussian geometry, compositing, ambiguity, opacity-field, and ZNCC operators.
- Experimental RaDe-GS, AmbiSuR, and GOF Studio recipes.
- Shared training, checkpoint resume, evaluation, mesh export, and local viewer.
- A separately installed Unbiased Surfel / PGSR-style auxiliary package in the
  full repository source archive. It is not installed by the main wheel and
  does not add Studio recipes.

## Distribution

The GitHub pre-release includes a main Python wheel, a main source distribution,
and a complete public source ZIP including the companion. External CUDA
renderers, third-party source trees, datasets, model weights, private scan
outputs, and local operational records are excluded.

The public snapshot also omits local server orchestration utilities and tests
specific to those utilities. Operator, runtime, component, and synthetic
Studio integration tests are retained.

## Verification

The release verification record is published alongside the release assets.
It covers local CPU tests, source-distribution rebuilding, an installed-wheel
check, and an analytic demo. GPU builds and paper benchmark parity are not
established by these checks.

## Known limits

- Three Studio recipes are integrated; the companion remains independent.
- No stable API or production-support commitment.
- No complete real-scene or paper-metric acceptance claim.
- The CPU demo uses analytic initialization and is a workflow check.
- CUDA backends need a matching PyTorch/CUDA toolchain and their own checks.
- Optional dependency and weight licenses apply separately.

See the [roadmap](../ROADMAP.md) for the later operator-library and ecosystem
stages.
