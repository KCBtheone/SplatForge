# SplatForge 0.0.1a2

PGSR and Unbiased Surfel now use the Studio commands for generating presets,
training, resuming, and exporting meshes from their native checkpoints.
GOF and VCR-GauS are available in the same method registry.

The wheel ships the VCR-GauS and Unbiased Surfel CUDA sources. Both can build
their extensions on first use. Unbiased Surfel also supports reusing an
installed extension. PGSR and Unbiased Surfel use the same pinned gsplat
revision. Installation and COLMAP input requirements are in the
[setup guide](https://github.com/KCBtheone/SplatForge/blob/v0.0.1a2/docs/releases/pgsr-preview.md).

The release check covers the package layout and command wiring. CUDA builds,
training, and mesh extraction through the new entry points were not run for
this release.
